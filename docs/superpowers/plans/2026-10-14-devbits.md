# DevBits Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add DevBits: short vertical videos with their own full-screen swipe feed, a fifth phone tab, posting from Create and a tab on profiles.

**Architecture:** A DevBit is a `Post` with `kind: "devbit"` and an uploaded Mux video, so likes, comments, notifications and deleting reuse the post routes. Every list of regular posts goes through one filter (`withoutDevBits`), and `GET /api/devbits` serves the feed (shuffled per request) or one person's DevBits. The browser shows them in a snap-scrolling viewer that plays the DevBit on screen in Mux's bare `<mux-video>` element, with the app's own overlay.

**Tech Stack:** Next.js 15.5 App Router, React 19, TypeScript, Tailwind CSS 4, shadcn/ui (Radix), Mongoose 8, Mux (`@mux/mux-node`, `@mux/upchunk`, `@mux/mux-video` 0.31.5). Tests: `node:test` (`npm run test:unit`), `scripts/smoke.mjs` (API), `scripts/mobile-check.mjs` (headless Chrome over CDP).

**Spec:** `docs/superpowers/specs/2026-10-14-devbits-design.md`

## Global Constraints

- Post kinds: `"post"` (the default) and `"devbit"`. Posts stored before DevBits have no `kind` and are regular posts.
- A DevBit is an uploaded Mux video plus a caption, never a photo, code or a video link; at most 90 seconds (`MAX_DEVBIT_SECONDS = 90`) and 200 MB. Video posts keep their 2-minute limit.
- User-facing copy, verbatim: "DevBits can be at most 90 seconds long", "No DevBits yet", "Couldn't load DevBits", "Try again", "Couldn't play this one", "This DevBit was removed", "Link copied".
- `GET /api/devbits` returns the 200 newest DevBits in a new random order for each request; `GET /api/devbits?user=<username>` returns that person's (up to 200), newest first. Both answer in the same shape as `GET /api/posts`.
- `GET /api/posts`, similar posts and search never return DevBits.
- Phone tab bar: Home · Explore · Create · DevBits · Profile, DevBits with lucide's `Clapperboard`. The desktop sidebar links to `/devbits`.
- Playback: `<mux-video>` from `@mux/mux-video` at exactly `0.31.5`, a direct dependency. The DevBit at least 60% on screen plays and loops; the others pause. The next one preloads its metadata, the rest preload nothing. Videos start muted; the speaker button turns sound on for the rest of the visit. Tapping the video pauses or resumes it. Vertical clips fill the screen (`--media-object-fit: cover`); landscape ones show whole (`contain`).
- `/p/<id>` of a DevBit forwards to `/devbits/<id>`; `/devbits/<id>` of a regular post forwards to `/p/<id>`.
- Never print `.env.local` or any secret. Run nothing against production. The dev server runs on port 3210; port 3000 belongs to another project and must never be stopped.
- Mongoose caches schemas: restart the dev server after any change under `models/`.
- Mux's Free plan stores at most 10 videos, shared with the live site. Every test run deletes the Mux videos it made (test cleanup does it by passthrough); a phone-check run needs up to 6 at once.

```ts
// The two kinds of post. A DevBit is a short video with its own feed
// (/devbits); every other list shows regular posts only. It imports nothing,
// so the unit tests load it in Node.

export const POST_KINDS = ["post", "devbit"] as const
export type PostKind = (typeof POST_KINDS)[number]

// The most DevBits one feed request returns.
export const DEVBITS_PAGE = 200

export function isPostKind(value: unknown): value is PostKind {
  return POST_KINDS.includes(value as PostKind)
}

// Adds "not a DevBit" to a Mongo filter. Posts stored before DevBits have no
// kind and count as regular posts, which $ne matches.
export function withoutDevBits<T extends object>(filter: T = {} as T): T & { kind: { $ne: "devbit" } } {
  return { ...filter, kind: { $ne: "devbit" } }
}

// A new array with the same items in a random order (Fisher-Yates).
export function shuffled<T>(items: readonly T[], random: () => number = Math.random): T[] {
  const result = [...items]
  for (let i = result.length - 1; i > 0; i--) {
    const j = Math.floor(random() * (i + 1))
    ;[result[i], result[j]] = [result[j], result[i]]
  }
  return result
}
```

```ts
import { NextResponse } from "next/server"
import { connectToDatabase } from "@/lib/mongodb"
import Post from "@/models/Post"
import { getAuthUser } from "@/lib/auth"
import { handleRouteError } from "@/lib/http"
import { toPublicPost } from "@/lib/post-response"
import { DEVBITS_PAGE, shuffled } from "@/lib/post-kinds"

// DevBits for the swipe feed: the newest in a new random order each time, or
// one person's (?user=), newest first.
export async function GET(req: Request) {
  try {
    const user = new URL(req.url).searchParams.get("user")
    const viewer = await getAuthUser(req)
    await connectToDatabase()

    const filter = user ? { kind: "devbit", "author.username": user } : { kind: "devbit" }
    const devbits = await Post.find(filter).sort({ createdAt: -1 }).limit(DEVBITS_PAGE).lean()
    const ordered = user ? devbits : shuffled(devbits)
    return NextResponse.json(ordered.map((post) => toPublicPost(post, viewer)))
  } catch (error) {
    return handleRouteError(error, "DevBits error", "Failed to load DevBits")
  }
}
```

```tsx
"use client"

import { useEffect, useRef, useState, type CSSProperties } from "react"
import { muxThumbnailUrl } from "@/lib/media-urls"
import type { MuxVideoElement } from "@/types/mux-video"

interface DevBitVideoProps {
  playbackId: string
  // Plays while true, pauses otherwise.
  playing: boolean
  muted: boolean
  preload: "none" | "metadata" | "auto"
  // Vertical clips fill the screen; landscape ones show whole.
  fill: boolean
  // The browser refused to start it without a tap.
  onBlocked: () => void
  onError: () => void
}

// One DevBit's video: Mux's bare <mux-video> element, played, paused and
// muted from outside. Its code loads with the DevBits screen only.
export function DevBitVideo({ playbackId, playing, muted, preload, fill, onBlocked, onError }: DevBitVideoProps) {
  const ref = useRef<MuxVideoElement>(null)
  const [defined, setDefined] = useState(false)

  // Defines <mux-video> the first time a DevBit is shown.
  useEffect(() => {
    let cancelled = false
    import("@mux/mux-video").then(() => {
      if (!cancelled) setDefined(true)
    })
    return () => {
      cancelled = true
    }
  }, [])

  useEffect(() => {
    if (defined && ref.current) ref.current.muted = muted
  }, [defined, muted])

  useEffect(() => {
    const video = ref.current
    if (!defined || !video) return
    if (!playing) {
      video.pause()
      return
    }
    video.play().catch((error: unknown) => {
      if (error instanceof DOMException && error.name === "NotAllowedError") onBlocked()
    })
  }, [defined, playing, onBlocked])

  useEffect(() => {
    const video = ref.current
    if (!video) return
    video.addEventListener("error", onError)
    return () => video.removeEventListener("error", onError)
  }, [onError])

  return (
    <mux-video
      ref={ref}
      playback-id={playbackId}
      poster={muxThumbnailUrl(playbackId, 720)}
      preload={preload}
      muted
      loop
      playsinline
      style={{ width: "100%", height: "100%", "--media-object-fit": fill ? "cover" : "contain" } as CSSProperties}
    />
  )
}
```

```tsx
// A list that snaps one DevBit per screen. The DevBit at least 60% on screen
```

```tsx
"use client"

import { useEffect, useState, type ReactNode } from "react"
import Link from "next/link"
import { useRouter } from "next/navigation"
import { Button } from "@/components/ui/button"
import { useAuth } from "@/contexts/auth-context"
import { DEVBITS_HEIGHT, DevBitsViewer } from "@/components/devbits/devbits-viewer"
import type { PostType } from "@/lib/types"

interface DevBitsScreenProps {
  // Open at this DevBit (/devbits/<id>).
  startId?: string
  // Only this person's DevBits, newest first (?user=).
  user?: string
}

type Status = "loading" | "ready" | "missing" | "error"

// What the DevBits screen shows: the shuffled feed, or one person's DevBits,
// opened at the linked DevBit. A link to a regular post goes to its page.
export function DevBitsScreen({ startId, user }: DevBitsScreenProps) {
  const { authFetch, loading: authLoading } = useAuth()
  const router = useRouter()
  const [devbits, setDevbits] = useState<PostType[]>([])
  const [startIndex, setStartIndex] = useState(0)
  const [status, setStatus] = useState<Status>("loading")
  const [attempt, setAttempt] = useState(0)

  useEffect(() => {
    // Wait for the stored session, so likes are the viewer's own.
    if (authLoading) return
    let cancelled = false

    const load = async () => {
      setStatus("loading")
      try {
        let start: PostType | null = null
        if (startId) {
          const response = await authFetch(`/api/posts/${startId}`)
          if (cancelled) return
          if (response.status === 404) return setStatus("missing")
          if (!response.ok) throw new Error("Failed to load the DevBit")
          start = (await response.json()) as PostType
          if (start.kind !== "devbit") return router.replace(`/p/${startId}`)
        }
        const response = await authFetch(user ? `/api/devbits?user=${encodeURIComponent(user)}` : "/api/devbits")
        if (!response.ok) throw new Error("Failed to load DevBits")
        const list = (await response.json()) as PostType[]
        if (cancelled) return

        const first = start
        if (!first) {
          setDevbits(list)
          setStartIndex(0)
        } else if (user) {
          const index = list.findIndex((devbit) => devbit._id === first._id)
          setDevbits(index >= 0 ? list : [first, ...list])
          setStartIndex(Math.max(index, 0))
        } else {
          setDevbits([first, ...list.filter((devbit) => devbit._id !== first._id)])
          setStartIndex(0)
        }
        setStatus("ready")
      } catch {
        if (!cancelled) setStatus("error")
      }
    }

    load()
    return () => {
      cancelled = true
    }
  }, [authFetch, authLoading, startId, user, router, attempt])

  if (status === "loading") return <div className={`animate-pulse bg-black md:rounded-lg ${DEVBITS_HEIGHT}`} />
  if (status === "error") {
    return (
      <Message text="Couldn't load DevBits">
        <Button variant="secondary" onClick={() => setAttempt((count) => count + 1)}>
          Try again
        </Button>
      </Message>
    )
  }
  if (status === "missing") {
```

```tsx
      })
    return () => {
      cancelled = true
    }
  }, [username, authFetch, authLoading, attempt])

  if (status === "loading") {
    return (
      <div className="grid grid-cols-3 gap-1 md:gap-4">
        {[0, 1, 2].map((index) => (
          <div key={index} className="aspect-[9/16] animate-pulse bg-muted" />
        ))}
      </div>
    )
  }
  if (status === "error") {
    return (
      <div className="py-10 text-center">
        <p className="text-muted-foreground">Couldn&apos;t load DevBits</p>
        <Button variant="outline" className="mt-4" onClick={() => setAttempt((count) => count + 1)}>
          Try again
        </Button>
      </div>
    )
  }
  if (devbits.length === 0) return <p className="py-10 text-center text-muted-foreground">No DevBits yet.</p>

  return (
    <div className="grid grid-cols-3 gap-1 md:gap-4">
      {devbits.map(
        (devbit) =>
          devbit.muxVideo && (
            <Link
              key={devbit._id}
              href={`/devbits/${devbit._id}?user=${encodeURIComponent(username)}`}
              className="relative aspect-[9/16] overflow-hidden bg-black"
            >
              {/* eslint-disable-next-line @next/next/no-img-element -- Mux thumbnail */}
              <img
                src={muxThumbnailUrl(devbit.muxVideo.playbackId, 360)}
                alt={devbit.caption}
                loading="lazy"
                className="h-full w-full object-cover"
              />
              <Play className="absolute right-2 top-2 h-5 w-5 fill-white text-white drop-shadow" />
            </Link>
          ),
      )}
    </div>
  )
}
```
